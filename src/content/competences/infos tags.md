La règle : si deux tags donnent systématiquement les mêmes résultats quand on filtre, il faut n'en garder qu'un.

Technologies : raisonner par projet, pas par couche
Tu te demandes si un thème WordPress sur mesure c'est front, back ou full-stack. La réponse : ton visiteur s'en fiche. Ce qui l'intéresse c'est la techno utilisée.
Donc ne tag pas "Développement front-end" ou "Développement full-stack" dans les technologies. Tag les outils réels :
ProjetTechnologies taguéesThème WP sur mesureWordPress, PHP, HTML/CSS, JavaScriptSite de formation AstroAstro, React, MDX, Tailwind CSSSite vitrine ReactReact, Next.js, Tailwind CSSPortfolioAstro, TypeScript, Tailwind CSSLanding page simpleHTML/CSS, JavaScript
Le filtre "WordPress" affichera tous tes projets WP. Le filtre "React" tous tes projets React. C'est bien plus utile que "full-stack" qui ne dit rien de concret.
